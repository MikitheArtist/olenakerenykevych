## About me

I didn't start in tech — I spent over a decade in environmental engineering, tracking down inconsistencies in compliance data and asking "but why does this number not match?" more times than I can count. Turns out that instinct translates surprisingly well to QA.

Since switching paths, I've built a portfolio testing real, live systems rather than staying in theory: an airline booking flow, a REST API, an e-commerce demo. Along the way I've found everything from broken form validation to a critical authentication bypass that let a login succeed with any password, including for users that didn't exist.

I like the moment right before you file a bug — when something looks "probably fine" and you decide to poke it one more time anyway. That's usually where the interesting stuff is.

Currently building toward a Manual QA role, with a growing interest in API testing and test automation fundamentals.
